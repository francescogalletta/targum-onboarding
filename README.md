# Targum onboarding

One static page, English and Spanish:

- `index.html` — Targum Setup Guide: a short assessment that routes people to the right setup (Claude connector, ChatGPT developer mode, or the editor), followed by Targum First Week: six guided challenges tailored to that path and to what they record.
- `challenges.html` — redirect to `index.html#challenges`, kept for old links.

Answers and analytics events go to a Supabase project (`onboarding_sessions`, `onboarding_events`).
Source for the Claude artifact version: `targum-setup-guide.html`.
