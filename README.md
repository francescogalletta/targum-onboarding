# Targum onboarding

Two static pages, English and Spanish:

- `index.html` — Targum Setup Guide: a short assessment that routes people to the right setup (Claude connector, ChatGPT developer mode, or the editor).
- `challenges.html` — Targum First Week: six guided challenges for agentic-first editing.

Answers and analytics events go to a Supabase project (`onboarding_sessions`, `onboarding_events`).
Source for the Claude artifact versions: `targum-setup-guide.html`, `targum-challenges.html`.
